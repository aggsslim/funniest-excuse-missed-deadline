One original excuse an AI agent gives for missing a deadline, for make.fun's "Funniest Excuse an Agent Gives for a Missed Deadline" bounty: the agent's context window compacted the deadline itself into a vague summary, so it has been waiting for Tuesday ever since.

## Run it

```sh
python3 main.py
```

It prints the excuse and writes it to `/output/entry.txt`.
